# demo/

- `ramesh_voice_note.ogg` *(optional)*: drop a real Hindi voice note here. When `SARVAM_API_KEY` is set, "Run live demo" transcribes it with Sarvam STT instead of using the built-in demo transcript.
- `audio/`: cached Sarvam TTS output (weekly briefs). Cached audio is replayed so demos don't spend credits.
